## 明天再看 for Mac

- [Product and download page](mingtianzai/)
- [Mac privacy policy](mingtianzai/privacy.html)
- [Support for Mac and iOS](wcmdn/support.html)

The Mac release is version 1.0 (10), supports macOS 14 and later on Apple silicon and Intel, and includes a Developer ID signed and Apple-notarized app. The disk image container is not separately notarized. Forwarded article URLs can sync after optional official-account binding; article bodies are fetched by each device. Notes, highlights, and reading progress stay on the device. Markdown exports can be used with a user-chosen AI tool; there is no built-in AI summarization or automatic AI upload.

Internal links are relative so the same static files can run under the GitHub Pages project path or a custom-domain root. The App filing number is labeled as an App filing on the product page and is not presented as the website's filing number.
